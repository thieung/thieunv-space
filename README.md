# thieunv-space

Trang cá nhân của Thiệu Nguyễn ([@thieung](https://github.com/thieung)): giới thiệu, dự án, vault, workflow & tools, đọc tin, tư vấn 1:1, thực hành và liên hệ.

Một file tĩnh duy nhất, không cần build. Mở `index.html` trong trình duyệt để xem.

- Hồ sơ cố định bên trái, mỗi lúc hiện một mục bên phải.
- Dock ở dưới để chuyển mục; phím 1–8 và Space cũng dùng được, URL đổi theo mục (`#du-an`, `#tu-van`, …).
- Có chế độ sáng/tối và giao diện điện thoại.

Chữ trong ngoặc vuông `[...]` là nội dung giữ chỗ, cần thay bằng nội dung thật. Phần đặt lịch hiện là bản demo, chưa nối hệ thống thật.
